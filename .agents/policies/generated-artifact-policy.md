# Generated Artifact Policy

## Default Stance
- Do not overwrite generated files, model outputs, predictions, cached data,
  build artifacts, reports, screenshots, notebooks, or PDFs unless explicitly
  asked.

## Inspection and Modification
- If a generated artifact is relevant, identify the path and ask before
  inspecting or modifying it.
- Treat outputs from training, inference, reporting, and build pipelines as
  potentially valuable baselines.

## ML and Data Projects
- Preserve baselines.
- Use new output directories for experiments or regenerated artifacts.
- Prefer additive changes over replacement when comparing runs.
