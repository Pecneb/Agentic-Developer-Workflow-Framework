# Outcome Reporting Policy

## Required Reporting
- Report what changed.
- Report the verification command or check that was run.
- Report pass or fail status.
- Report skipped checks explicitly.
- Report residual risk or uncertainty.

## Truthfulness Rules
- Never say "done" if tests failed or were not run without saying so.
- If verification was partial, say what remains unverified.
- If a change was blocked, state the blocker instead of implying completion.
