# Small Fix Workflow

## Use For
- typo fixes
- small config changes
- narrow single-file fixes

## Steps
1. Read the relevant file.
2. Edit directly only if the change is truly trivial.
3. Run a targeted verification check.
4. Report what changed and whether verification passed.

## Rules
- No broad planning is needed.
- If the task expands beyond trivial scope, switch to
  `.agents/workflows/nontrivial-change.md`.
